# N2 — Ghost in the Wire · Hints

Progressive hints. Reveal one at a time. The official solution is never
exposed through hints.

**H1**
An incident timeline is often more useful than examining every packet
individually. Start by understanding when the unusual activity occurred.

**H2**
DNS traffic is not limited to ordinary hostname lookups. Pay attention to the
structure of the requested names.

**H3**
A suspicious source IP is only an address. Can you establish which device was
using it at the time?

**H4**
DNS query names can contain more information than the destination domain
itself. Examine the labels carefully.

**H5**
The captured data appears to have been divided into multiple pieces.
Reconstruct the original sequence before attempting to decode it.
